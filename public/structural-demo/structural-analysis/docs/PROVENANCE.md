# Public provenance boundary

The private research pipeline used seven canonical engineering sources spanning moment distribution, slab/equivalent-frame calculations, Nepal structural/seismic codes, and computational structural mechanics.

The private pipeline was:

`source intake → source-faithful extraction → provenance QA → normalized engineering knowledge → formal benchmark suite → solver/cross-validation freeze`

This public subtree contains only derived code, compact numerical regression fixtures, validation summaries, and capability boundaries needed to make the computational method inspectable.

It intentionally excludes:

- source PDFs and copyrighted binaries;
- the complete source-faithful extraction corpus;
- private Google Drive URLs/IDs;
- internal checkpoints and governance records;
- credentials or repository tokens.

The public regression values are numerical facts/derived test fixtures; they are not reproductions of source pages.
