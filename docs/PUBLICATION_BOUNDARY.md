# Publication boundary

## Public

- derived solver/processing source code;
- self-contained regression tests;
- public-safe validation summary;
- known discrepancy statement;
- capability/limitation documentation.

## Private / governed Drive only

- seven original source binaries;
- source-faithful extraction JSONL;
- private Drive identifiers and links;
- internal source locators beyond what is necessary for public bibliographic explanation;
- governance/control/checkpoint files;
- external client/project models unless separately sanitized and approved.
